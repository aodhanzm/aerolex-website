# _archive/

Everything aerolex.dev used to be. **Preserved, never deleted** — and, since 2026-08-17, no longer
published.

## Why the folder name starts with an underscore

The host builds this site with Jekyll, which refuses to publish any folder whose name begins with
an underscore. That single character is what makes the difference between "kept in the files" and
"kept on the web" — and NZ chose kept-in-the-files (2026-08-17).

⚠ **Renaming this folder republishes everything in it.** If these pages ever need to go back on the
web, that is the deliberate act: move what should be live back out to the root.

## What is still live at aerolex.dev

The game launchpad at `/`, the privacy notice at `/privacy/`, the shared `assets/` folder, and
`uploads/`. Nothing else.

## Why this was archived rather than deleted

NZ's decision, Launch & Live Roadmap §2: **the game takes over aerolex.dev entirely**, made in full
knowledge that a consulting prospect who looks the domain up will now find a game. The consulting
work is not abandoned; it simply does not own this domain any more.

`assets/styles.css` — the consulting site's stylesheet — is deliberately **left in place** rather
than archived with the pages, because the archived pages still reference it and would otherwise be
restored as unstyled HTML. The new site uses `assets/scene.css` and does not load it.

## Reactivation note, carried forward from the previous archive

Do not blindly restore. The v1 copy uses em dashes throughout, which conflict with the Anti-AI
Writing Style rules adopted 2026-04-20. Restore and rewrite; do not copy-paste.
